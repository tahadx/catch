# AGENTS.md

Project instructions for coding agents live in [CLAUDE.md](CLAUDE.md). Read it first.

In a feature worktree, read the branch brief in `plan/AGENTS.md` next (local
only, gitignored). It wins over stale plan text. A checkout may also carry a
local `plan.md`; both are gitignored and neither is committed.

(This is a plain file, not a symlink: `omarchy plugin validate` rejects symlinks
inside a plugin.)
